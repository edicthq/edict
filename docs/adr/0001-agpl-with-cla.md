# AGPL-3.0 with a CLA, MIT for client libraries

The server and apps are AGPL-3.0, so anyone hosting a modified Edict must publish their changes. Contributors sign a CLA, which keeps the option of a paid hosted or enterprise edition open. We picked a CLA over a DCO for that reason, and accept that some contributors will skip us because of it. `packages/client`, the CLI and MCP config examples are MIT, so anyone can embed them in their own agents without license questions.

## Considered options

- MIT or Apache-2.0: a competitor could host Edict commercially and give nothing back.
- AGPL with a DCO: less friction for contributors, but we could never relicense.
